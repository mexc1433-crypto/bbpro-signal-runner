# 🤖 BBPro Signal Bot

بوت إشارات تداول العملات الرقمية المتقدم

## ✨ المميزات

- **8 استراتيجيات تداول** متقدمة
- **17+ مؤشر فني** (RSI, MACD, Bollinger, EMA, Ichimoku, SuperTrend, Fibonacci, إلخ)
- **3 أنواع صفقات**: سريع (Scalping), متوسط (Medium), بعيد (Swing)
- **تقسيم رأس المال**: $10, $20, $30, $50, $60, $70, $100, $150, $200, $300, $500, $1000+
- **إدارة مخاطر متقدمة** مع حساب أحجام الصفقات والرافعة المالية
- **قناتين تيليجرام**: عامة (ربح صغير) وخاصة (ربح كبير)
- **تحليل متعدد الأطر الزمنية** (5m, 15m, 1h, 4h, 1d)
- **تحليل معنويات السوق** (Fear & Greed Index)

## 📡 القنوات

### القناة العامة
- 1-3 إشارات يومياً
- صفقات سريعة (Scalping) + متوسطة (محدودة)
- مخاطرة منخفضة فقط
- ربح صغير (0.5-1.2%)

### القناة الخاصة
- 1-10 إشارات يومياً
- صفقات متوسطة + بعيدة (لا سكالبينج)
- كل مستويات المخاطرة
- ربح كبير (1.5-8%)
- تحليل مفصل + كل مستويات رأس المال

## 🚀 التشغيل

### 1. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 2. إعداد المتغيرات البيئية
```bash
cp .env.example .env
# عدل ملف .env وأضف:
# - BOT_TOKEN: توكن البوت من @BotFather
# - PUBLIC_CHANNEL_ID: معرف القناة العامة
# - PRIVATE_CHANNEL_ID: معرف القناة الخاصة
# - ADMIN_ID: معرف حسابك في تيليجرام
# - EXCHANGE: mexc أو binance
```

### 3. تشغيل البوت
```bash
python main.py
```
